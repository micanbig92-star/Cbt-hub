# CBT HUB Offline Mode

This is the separate offline version of CBT HUB.

## How it will work
- The administrator runs the local server on a laptop or phone.
- Student laptops connect through the same Wi-Fi router or hotspot.
- Students can take exams without internet access.
- Results are saved locally.
- Results automatically sync when internet returns.

## Important
Never delete unsynchronized exam results.
The administrator's device must remain powered on during exams.
Test the system carefully before using it for official examinations.
